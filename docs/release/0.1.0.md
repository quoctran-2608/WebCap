# WebCap 0.1.0 release candidate notes

WebCap 0.1.0 is the first internal release candidate of the local-first Chrome extension for reliable viewport, full-page, region, element, scroll-area, image, and paged-PDF capture.

## Highlights

- Visible PNG/JPEG/WebP capture with local preview and download verification.
- CDP-first tiled full-page capture with bounded scroll fallback, cancellation, restoration, and explicit partial-result handling.
- Region, element, open-shadow-root, and two-dimensional scroll-container selection/capture.
- Page-at-a-time PDF export with A4/Letter/fit-width settings, editor persistence, retry without recapture, integrity checks, and memory guards.
- Original PDF passthrough with exact optional origin/file permission and byte integrity checks.
- Vietnamese/English UI, keyboard/live-region accessibility, restricted-page guidance, safe diagnostics, and local-first privacy documentation.
- Deterministic store ZIP, checksum/release manifest, packaged lifecycle tests, browser compatibility gate, and release/store handoff documentation.

## Safety and privacy

The release candidate adds no account, backend, analytics, advertising, cloud sync, remote diagnostics upload, remote executable code, default host permission, or new required Chrome permission. Screenshot/PDF bytes remain local unless the user separately shares the downloaded file.

## Upgrade and rollback

The lifecycle gate simulates an update from 0.0.9 to 0.1.0 on the same profile and verifies local setting persistence. Chrome Web Store updates must use a version larger than 0.1.0. Rollback is operational—disable distribution or upload a corrected higher version—because a published version number cannot be reused.

## Known limitations

See [`../known-limitations.md`](../known-limitations.md). Restricted browser surfaces, protected media, closed shadow roots, highly dynamic pages, very large outputs, and some authenticated/viewer PDF sources have explicit fallback or workaround guidance.

## Publication status

This repository and its workflow prepare and test the release candidate only. No tag, GitHub Release, Chrome Web Store upload, review submission, or public publication occurs without explicit release-owner approval.
