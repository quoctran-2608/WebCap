# WebCap 0.2.0 release-candidate notes

Date: 2026-08-06  
Status: release candidate complete; ready for review

## Highlights

- Reliable region drawing with pointer and keyboard workflows.
- Adaptive full-page capture beyond 100,000 CSS pixels with resumable frontier and honest partial guards.
- Automatic PDF for full-page/scroll-area and guarded direct images for region/element, with no-recapture PDF fallback.
- Ownership-safe New capture/reset lifecycle.
- Durable per-mode settings, event-driven progress and simplified accessible popup.
- Explicit 0.1.0 → 0.2.0 settings/locale migration and minimum/previous/current Chrome compatibility.
