# WebCap 0.1.0 gap audit

Date: 2026-08-04  
Target disposition: WebCap 0.2.0 roadmap  
Scope: user-visible gaps, contract mismatches, reliability risks, deferred MVP SHOULD/COULD items and platform limitations.

This audit does not invalidate the 0.1.0 release evidence. The automated release gate passed and no P0/P1 was accepted. The purpose is to compare the shipped implementation and user experience with the original PRD, known limitations and real usage feedback, then assign each gap a deliberate disposition.

# 1. Classification

- **0.2 MUST**: blocks the requested 0.2.0 user journey or creates a dead-end/misleading experience.
- **0.2 SHOULD**: important quality/contract closure; may ship only with explicit owner disposition if deferred.
- **Platform/documentation**: cannot be fully fixed without violating Chrome/platform boundaries; improve detection/copy/help/tests.
- **Defer 0.3+**: useful but not required for the focused 0.2.0 release.

# 3. Existing 0.1.0 capabilities that must not regress

- Visible viewport PNG/JPEG/WebP preview/download and session restoration.
- CDP tiled full-page capture and deterministic scroll fallback.
- Region/element/scroll-area CSS coordinate correctness and page restoration.
- Smart/preserve/remove fixed-sticky policies at engine level.
- Page-at-a-time PDF export with one decoded tile and memory/integrity guards.
- PDF editor reorder/remove/settings/retry/download.
- Original PDF passthrough with exact optional permissions.
- Local-first storage, metadata-only runtime messages, no analytics/backend/remote code.
- Vietnamese/English i18n, safe diagnostics and permission rationale.
- Packaged install/update/uninstall and deterministic ZIP.

# 4. Platform/documentation boundaries

These remain limitations, not promises to bypass browser security:

| ID       | Boundary                                                                                                           | 0.2 action                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |

| PLAT-002 | DRM/protected video/canvas/hardware overlays may be blank.                                                         | Detect/report when possible; no bypass.                                             |
| PLAT-003 | Cross-origin frame pixels can appear, but DOM selection is unavailable.                                            | Allow outer-element/region capture; explain limitation.                             |
| PLAT-004 | Closed shadow-root internals cannot be traversed.                                                                  | Select host or region.                                                              |
| PLAT-005 | `captureVisibleTab` scroll engines require source tab to remain active.                                            | Clear preflight/progress warning; fail before storing next tile; restore page.      |
| PLAT-006 | Original PDF depends on authentication, source type, optional host/file permission and Chrome file-access setting. | Preserve fallback and contextual permission copy.                                   |
| PLAT-007 | Captured pixels vary with device fonts, GPU, zoom and page state.                                                  | Document controlled-profile guidance.                                               |
| PLAT-008 | Desktop Chrome 116+ is the compatibility commitment.                                                               | Test minimum/current/previous stable; do not claim other browsers without evidence. |

# 6. Release-blocking defect policy for 0.2.0

Any new defect in these classes blocks RC:

- missing or duplicated logical content;
- region selector fails to appear after acknowledged start;
- selector UI included in output;
- orphan job/root/tab lock after cancel/reset/launch failure;
- page scroll/focus/style not restored;
- reset deletes unrelated capture/settings/downloaded files;
- resume duplicates prefix or resumes on a changed document;
- binary/page content leaks through messages/logs/network;
- permission is requested before explicit user intent;
- output represented as complete when guard produced partial.
